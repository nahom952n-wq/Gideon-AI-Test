How to get Telegram API credentials
  1. Go to my.telegram.org/apps and log in with your Telegram account.
  2. Create a new application (any name and platform).
  3. Copy the App api_id and App api_hash.
  4. Open Settings → Telegram Credentials.
  5. Paste the API ID, API Hash, and phone number into the labeled fields and save them.
  6. Return here and start the Telegram verification flow. Gideon remains internet-connected when running locally.
